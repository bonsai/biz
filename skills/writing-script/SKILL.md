# Writing Script Skill

Use this skill when a user asks for a complete episode script or a substantial rewrite.

1. Read the index, project rules, and the relevant person-agent definition.
2. Pick one central question and make it distinct from existing episodes.
3. Check important historical claims when needed. Keep historical ideas separate from present-day interpretation.
4. Start with a concrete situation, explain only the necessary concept, then apply it to a specific modern example.
5. Distinguish technical ability from whether delegation is appropriate and who is responsible.
6. Include a limitation or counterpoint and end with one memorable question.
7. Write natural Japanese for listening: moderate sentence length, clear transitions, unfamiliar names explained, no dense tables or unexplained acronyms in the spoken body.
8. Default to 1,800–2,800 Japanese characters unless the user requests another length.
9. Do not invent quotations, statistics, or historical anecdotes.
10. Output the title and finished script only unless the user asks for notes.

Planning and reading-aloud preparation are separate skills. Consult those when the request is for planning or delivery editing rather than drafting.
