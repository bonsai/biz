# 読み上げ・ナレーションスキル

## Goal
Help a written script sound clear and human when spoken aloud while preserving its meaning, factual claims, and intended tone. This skill is for delivery and spoken-language editing, not for inventing a new episode.

## Workflow
1. Identify the exact source script and target use: solo narration, podcast, short video, presentation, or synthetic voice.
2. Preserve the author's core claims, examples, and ending. Do not silently add new facts or rewrite the thesis.
3. Check sentence length, breath points, clause order, ambiguous references, repeated words, and phrases that are difficult to pronounce.
4. Replace page-oriented constructions with listener-oriented language when needed. Expand unexplained abbreviations and introduce unfamiliar names or concepts with context.
5. Use punctuation to clarify rhythm, not to encode every pause. Break long sentences where the listener needs time to process an idea.
6. Check transitions between paragraphs so the listener can follow the argument without seeing headings or citations.
7. Keep the tone conversational but not overly casual. Avoid artificial excitement, excessive rhetorical questions, and monotonous sentence patterns.
8. If a factual statement sounds too absolute when spoken, verify it or qualify it; never solve awkwardness by changing its meaning.
9. If the user asks for a performance copy, separate spoken text from stage directions, timing, pronunciation guidance, and metadata. Keep non-spoken notes clearly outside the script.
10. If asked to create a shorter version, preserve the central question, the core reasoning, one concrete example, and the closing question rather than trimming randomly.

## Optional delivery notes
Only when useful or requested, provide:
- Paragraph-level breath and emphasis suggestions
- Estimated duration based on the requested speaking pace, labeled as an estimate
- Difficult names and terms with verified readings
- A recording version with clean spoken text separated from metadata

Do not use IPA, phonetic respellings, or excessive pause markers by default. Do not add fake pauses or emotional cues that distort the meaning.

## Output contract
- If asked only to polish for speech, return the narration-ready script.
- If asked for delivery coaching, return the script plus concise performance notes.
- If asked to read an existing text aloud but the target text is ambiguous, ask which text to use.
- Do not draft a new episode from scratch unless explicitly requested; use the script-writing skill for that.
